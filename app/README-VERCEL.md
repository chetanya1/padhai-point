# Padhai Point — standalone Vercel deployment

This is the standalone React 19 + TanStack Start project, configured with Nitro for Vercel. It no longer needs Higgsfield workspace packages or hosting runtime.

## Deploy
1. Create a GitHub repository you own (suggested name: padhai-point).
2. Upload/push the contents of this project to the repository root (the app directory contents, not the parent archive folder).
3. Sign in to Vercel and import that repository.
4. Keep Framework Preset as TanStack Start, Root Directory ./, Build Command npm run build (or leave auto-detected), and deploy.
5. Vercel assigns a free *.vercel.app address. Choose project name padhai-point if available.
6. Check the production deployment, call link, Google Maps link, and mobile view before sharing.

## Local development
Use Node.js 22+ and npm or Bun. From this directory, run npm install, npm run dev. To verify a production build, run npm run build.
